DevPilot AI

I built a workflow that turns GitHub issues into proposed patches with test results a human reviewer can inspect.

Go to the interactive demo

My role

I designed the LangGraph workflow, built the dashboard for inspecting decisions and failures, and added an approval step before pull request submission.

Approach

The workflow investigates an issue, proposes a patch and runs tests in an isolated Docker environment. If checks fail, the workflow uses the failure details to revise the patch.

Evaluation

In the original 30-task evaluation, iterative patch refinement increased resolved tasks from 17 to 22.
